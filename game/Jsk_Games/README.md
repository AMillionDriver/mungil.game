# JSk13Games Collection

This folder contains games cloned from the JSk13Games repository (https://github.com/AMillionDriver/games.git).

## Games in this collection:
- **Asteroids** - Classic arcade space shooter
- **Pacman** - Classic maze chase game
- **Snake** - Classic snake game
- **Tetris** - Classic puzzle game

## Adding More Games

To add more games from JSk13Games:

1. Clone the repository (already done):
   ```
   git clone https://github.com/AMillionDriver/games.git
   ```

2. Copy a game folder to `game/Jsk_Games/`:
   ```
   copy games\games\game-name\* game\Jsk_Games\Game-Name\
   ```

3. Add a new game card to `index.html` with the attribution text

4. Test the game in your browser
