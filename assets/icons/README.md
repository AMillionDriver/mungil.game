# PWA Icons

## Required Icons

Create PNG icons with the following sizes:

| Size | Filename | Use Case |
|------|----------|----------|
| 72×72 | `icon-72.png` | Small devices |
| 96×96 | `icon-96.png` | Medium-small devices |
| 128×128 | `icon-128.png` | Medium devices |
| 144×144 | `icon-144.png` | Medium devices |
| 152×152 | `icon-152.png` | Medium-large devices |
| 192×192 | `icon-192.png` | Android home screen |
| 384×384 | `icon-384.png` | Large devices |
| 512×512 | `icon-512.png` | App install |

## How to Create

1. Design a single icon (preferably 512×512 or larger)
2. Use an image editor or online tool to resize to all required sizes
3. Save as PNG with transparent background
4. Place all files in this folder

## Testing

After adding icons, test PWA installation:

1. Open site in Chrome/Edge
2. Look for "Install" button in address bar
3. Test on mobile device (iOS/Android)
