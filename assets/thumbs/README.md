# Game Thumbnails

## How to Add Thumbnails

1. Take a screenshot from each game (recommended size: 400x240px or 16:9 aspect ratio)
2. Save the image in this folder with the same filename as the game folder
3. Use `.jpg` format for better compression

### File Naming Convention
- Game folder: `neon-cyber-survivor` → Thumbnail: `neon-cyber-survivor.jpg`
- Game folder: `08800-space-organizer` → Thumbnail: `08800-space-organizer.jpg`

## Tips
- Screenshots should show exciting gameplay moments
- Avoid text-heavy screens
- Keep file sizes under 100KB for fast loading
