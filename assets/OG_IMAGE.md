# Open Graph / Social Sharing Preview

## OG Image Requirements

Untuk tampilan preview yang bagus saat share link di social media:

**Size:** 1200 × 630px (1.91:1 aspect ratio)
**Format:** PNG atau JPG
**Max size:** 5MB

## File Structure

```
assets/
└── og-preview.png  # ← Letakkan gambar di sini
```

## How to Create

1. Design banner dengan ukuran 1200×630px
2. Tambahkan logo/text "Mini Game Hub"
3. Export sebagai PNG/JPG
4. Save ke `assets/og-preview.png`

## Testing

Setelah upload, test di:
- [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/)
- [Twitter Card Validator](https://cards-dev.twitter.com/validator)
- [LinkedIn Post Inspector](https://www.linkedin.com/post-inspector/)
